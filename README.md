# ACTS Auctioneer Training Website

Official website source for [ACTS: Auctioneer Training](https://apps.apple.com/au/app/acts-auctioneer-training/id6802531027).

## About

ACTS is a purpose-built auctioneer training app for speed, accuracy, memory and confident decision-making under pressure. This repository is intentionally separate from the live ACTS support and legal-pages repository.

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

## Production build

```bash
npm run build
```

The site includes the real app interface, a web-ready demonstration video, current Australian ACTS Pro pricing, a downloadable sample auction script, and links to the existing support, privacy, terms and billing pages.
